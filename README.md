# Dockshift

Dockshift is a native SwiftUI macOS menu-bar app with separate Keyboard, Mouse, Monitor, and Dock Setup modules.

The current version is only the app shell. Upstream code has not been copied yet.

Planned feature ownership:

- Keyboard: selected keyboard-mapping features from Karabiner-Elements.
- Mouse: selected mouse features from LinearMouse.
- Monitor: selected display features from MonitorControl.
- Dock Setup: selected Dock features from LinearMouse's DockKit.
